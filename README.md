# barca-wheel

A spinnable wheel that picks a random player from a team's starting lineup. Switch between FC Barcelona (2017), Portugal (2026 predicted) and Manchester City (2026).

Live page: https://raulg45bdn.github.io/Barca-wheel/

- Spin with the button, by tapping the wheel, or by dragging and flicking it.
- "Remove picked players" takes each pick off the wheel until you press Reset.
- Add or remove players by hand from the Squad list.

Everything is in `index.html` (player portraits are embedded). `apple-touch-icon.png` is the Home Screen icon.
